# M0 — Walking Skeleton: Design & Contracts

> Implements [PRD §12 M0](../../PRD.md). Scope: ledger + CAS + intent/world objects + T0 worktree worlds + one oracle + `mvo race` with N=2 **scripted** patches (no agent adapters yet). Exit criterion: `mvo audit` replays a toy race deterministically on another machine.
>
> Everything here is v0 and may break until M1. Requirement IDs (CP-x, DP-x…) refer to the PRD.

## Module layout

```
go.mod                      module github.com/coagente/multiverso   (Go ≥1.25)
cmd/mvo/                    CLI (stdlib flag; no cobra in M0)
internal/object/            canonical JSON + digests; Intent/World/Receipt/Decision types
internal/cas/               content-addressed store (sha256, file-based)
internal/ledger/            append-only hash-chained event log (SQLite via modernc.org/sqlite)
internal/gitx/              git shell-out: worktrees, apply, tree digests
internal/oracle/            Oracle interface + CommandOracle
internal/race/              v0 fixed orchestrator + decision function
internal/workspace/         .multiverso/ directory layout, config, open/init
testdata/toyrepo/           fixture: tiny python repo + two candidate patches (one passes, one fails)
```

Dependencies: **only** `modernc.org/sqlite` (CGo-free). Everything else stdlib. No cobra, no logrus.

## Canonical serialization & digests (`internal/object`) — DP-1, NFR-1

- Canonical JSON: keys sorted lexicographically at every level, no insignificant whitespace, UTF-8, integers only (no floats in v0 schemas), RFC3339 UTC timestamps.
- Digest = `"mv0:" + hex(sha256(canonicalJSON))`. Function: `Digest(v any) (string, []byte, error)` returns digest and canonical bytes.
- Every object carries `schema` (e.g. `"multiverso.dev/intent/v0"`). Digests are computed over the full canonical object.

Types (subset of PRD §5 sufficient for M0):

```go
type Intent struct {
    Schema   string   `json:"schema"`             // multiverso.dev/intent/v0
    Base     Base     `json:"base"`               // {commit, tree}
    Spec     Spec     `json:"spec"`               // {title, description}
    Budget   Budget   `json:"budget"`             // {max_candidates int, max_wall_ms int64}
    Policy   string   `json:"policy"`             // digest of Policy object
    CreatedAt string  `json:"created_at"`
}

type World struct {
    Schema        string   `json:"schema"`        // multiverso.dev/world/v0
    Intent        string   `json:"intent"`        // intent digest
    Tree          string   `json:"tree"`          // git tree digest after patch ("git:<sha1>")
    Env           string   `json:"env"`           // digest of env manifest (M0: {"go":"none","os":runtime.GOOS} + lockfile hashes if present)
    IsolationTier string   `json:"isolation_tier"`// "T0-worktree"
    Producer      Producer `json:"producer"`      // {adapter:"script@v0", model:"", identity_tier:"claimed", role:"generator"}
    Patch         string   `json:"patch"`         // CAS digest of the .patch bytes
    Outcome       string   `json:"outcome"`       // COMPLETED | CONFIG_ERROR | CRASH (M0 subset)
    CreatedAt     string   `json:"created_at"`
}

type Receipt struct {
    Schema    string    `json:"schema"`           // multiverso.dev/receipt/v0
    World     string    `json:"world"`            // world digest
    Oracle    OracleRef `json:"oracle"`           // {id, version, config}  config = digest of argv+timeout
    Execution Execution `json:"execution"`        // {argv []string, exit_code int, duration_ms int64, isolation_tier string}
    Result    Result    `json:"result"`           // {status "pass"|"fail"|"error", artifacts []string}  artifacts = CAS digests (stdout, stderr)
    Freshness Freshness `json:"freshness"`        // {basis:"construction", valid_for:{tree,env}}
    RecheckTier string  `json:"recheck_tier"`     // "V1-replayable"
    Family    string    `json:"family"`           // "suite"
    Cost      Cost      `json:"cost"`             // {wall_ms int64}
    CreatedAt string    `json:"created_at"`
}

type Decision struct {
    Schema    string   `json:"schema"`            // multiverso.dev/decision/v0
    Type      string   `json:"type"`              // SELECT | REJECT | ESCALATE
    Intent    string   `json:"intent"`
    Subject   []string `json:"subject"`           // world digest(s); winner first for SELECT
    Evidence  []string `json:"evidence"`          // receipt digests, sorted
    Policy    string   `json:"policy"`
    Rationale string   `json:"rationale"`         // human-readable, deterministic given inputs
    CreatedAt string   `json:"created_at"`
}

type Policy struct {
    Schema    string   `json:"schema"`            // multiverso.dev/policy/v0
    HardGates []string `json:"hard_gates"`        // M0: ["suite-pass"]
    Ranking   []string `json:"ranking"`           // M0: ["gate_pass","wall_ms_asc"]  (lexicographic)
}
```

**Determinism rule (NFR-1)**: `CreatedAt` participates in digests (objects are immutable records of what happened), but the **decision function must be a pure function of (policy, receipts)** — replay recomputes the decision from recorded evidence and must reproduce `Type`, `Subject`, `Evidence`, `Rationale` byte-for-byte. Ties broken by world digest ascending.

## CAS (`internal/cas`) — DP-2

- Layout: `.multiverso/cas/sha256/<first2>/<rest>` storing raw bytes; key = `"sha256:" + hex`.
- `Put([]byte) (key string, err)` (idempotent, write-to-temp + rename), `Get(key) ([]byte, error)`, `Has(key) bool`.

## Ledger (`internal/ledger`) — DP-1, NFR-3

SQLite file `.multiverso/ledger.db`, WAL mode. **Refuse network filesystems** is deferred to M1 (documented TODO). Single table:

```sql
CREATE TABLE events (
  seq         INTEGER PRIMARY KEY AUTOINCREMENT,
  ts          TEXT NOT NULL,              -- RFC3339 UTC
  type        TEXT NOT NULL,              -- event type, see below
  payload     BLOB NOT NULL,              -- canonical JSON of the object or event body
  payload_dig TEXT NOT NULL,              -- mv0: digest of payload
  prev_hash   TEXT NOT NULL,              -- chain hash of previous row ("" for seq 1)
  hash        TEXT NOT NULL               -- hex(sha256(prev_hash + "\n" + type + "\n" + payload_dig))
);
```

- Event types (M0): `intent.created`, `world.created`, `receipt.recorded`, `decision.recorded`, `race.started`, `race.finished`.
- API: `Append(type string, payload []byte) (seq int64, err)`, `Scan(fn func(Event) error) error`, `VerifyChain() error`.
- Append-only enforced by API (no update/delete statements anywhere) + `VerifyChain` on `mvo audit`.

## Git backend (`internal/gitx`) — XP-1, AG-4

Shell out to `git` (no go-git). Needed:
- `TreeDigest(dir) (string, error)` → `git rev-parse HEAD^{tree}` prefixed `"git:"`.
- `AddWorktree(repo, dst, commit) error` / `RemoveWorktree(repo, dst) error`.
- `Apply(dir, patch []byte) error` → `git apply --index` (M0 applies without committing; tree digest via `git write-tree` after `git add -A`).
- `Head(repo) (commit, tree string, err)`.
- All commands run with `-c core.hooksPath=/dev/null`, capture stderr into errors.

## Oracle (`internal/oracle`) — EP-1, EP-7

```go
type Oracle interface {
    ID() string          // "command"
    Version() string     // "v0"
    Run(ctx context.Context, worldDir string) (object.Receipt, error)
}
```

`CommandOracle{Argv []string, Timeout time.Duration}` runs argv in worldDir, captures stdout/stderr into CAS, maps exit 0 → `pass`, non-zero → `fail`, timeout/spawn error → `error`. Timeout kills the **process group**. Receipt is filled per the schema above; `valid_for.tree` = the world's tree digest.

**Toy fixture gate**: `python3 -m pytest -q` inside `testdata/toyrepo` copies. Guard: record collected-test count context later (M1); M0 just records exit code + streams.

## Race orchestrator (`internal/race`) — CP-2, CP-3, CP-6

`mvo race` v0, sequential (N=2; parallelism is M1):
1. Load intent + policy; `race.started` event.
2. For each patch file (sorted filename order) in `--patches <dir>`: create worktree at intent.Base.Commit → apply patch → compute tree digest → store patch in CAS → `world.created`. Apply failure ⇒ world with `Outcome:"CONFIG_ERROR"`, no receipts.
3. Run the oracle in each COMPLETED world → `receipt.recorded`.
4. Decision function `Decide(policy, worlds, receipts) Decision` (pure):
   - Hard gate `suite-pass`: world's suite receipt status == "pass".
   - ≥1 pass ⇒ `SELECT`, winner = best by ranking (gate_pass, then wall_ms ascending, tie → world digest asc); losers listed after winner in `Subject`.
   - 0 pass ⇒ `REJECT` (all subjects, rationale lists failing gates).
5. `decision.recorded`, `race.finished`; worktrees removed (kept under `--keep-worlds`).

## Workspace (`internal/workspace`)

- `mvo init` creates `.multiverso/{ledger.db,cas/,config.json,policies/default.json}`; refuses to re-init.
- `.multiverso/` is git-ignored by default (append to `.gitignore` if present; create otherwise).
- Config: `{ "schema":"multiverso.dev/config/v0", "default_policy":"<digest>" }`; the default Policy object is stored in CAS and recorded in the ledger at init.

## CLI (`cmd/mvo`)

```
mvo init
mvo intent new --title T [--desc D] [--budget-candidates 2] [--budget-wall-ms 600000]   → prints intent digest
mvo race <intent-digest> --patches <dir> --oracle-cmd "python3 -m pytest -q" [--keep-worlds]
mvo worlds <intent-digest>            table: world digest, outcome, gate, wall_ms
mvo explain <intent-digest>           renders the decision + rationale + evidence digests
mvo audit                             verify hash chain + recompute all decisions from evidence;
                                      exit 0 and print "OK: N events, M decisions replayed" iff identical
mvo audit --json                      machine-readable report
```

- Every verb supports `--dir <repo>` (default cwd). Errors to stderr, exit codes: 0 ok, 1 failure, 2 usage.
- No color, no spinner in M0.

## Acceptance script (CI runs this)

`scripts/m0-accept.sh`:
1. Create temp git repo from `testdata/toyrepo` (has a failing function + pytest suite).
2. `mvo init`; `mvo intent new`; `mvo race` with the two shipped patches (patch-a fixes the bug → suite passes; patch-b claims to but breaks another test → fails).
3. Assert `mvo explain` shows SELECT with patch-a's world as winner.
4. Copy the whole repo dir to a second location; `mvo audit --json` there; assert `replay_identical == true`.
5. Corrupt one ledger row with sqlite3 (flip a byte in payload); assert `mvo audit` now fails with chain error.

## Testing bar

- Unit tests per package (object: canonical JSON golden tests + digest stability; ledger: chain verify + tamper detection; cas: idempotent put; gitx: worktree lifecycle on a temp repo; race: decision function table tests incl. ties).
- `go vet` and `gofmt -l` clean. The acceptance script is the e2e test and runs in CI.

## Explicitly NOT in M0

Signing (TP-1 → M1), agent adapters (AG-1 → M1), containers (XP-1 T1 → M1), `refs/multiverso/*` publication (FI-1 → M1), parallel world execution, `mvo admit` (M1), Windows.
